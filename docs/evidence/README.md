# Реестр доказательств

[README](../../README.md)

Реальных runtime-артефактов пока нет. Этот файл задаёт критерии сбора и не является журналом выполненных работ.

Выполнена [проверка доступности 14 ноября 2026 года](2026-11-14-preflight.md): Docker Engine и Kubernetes API недоступны. Синтаксические проверки пройдены; функциональные кейсы остаются непроверенными.

## Статусы

- **Подтверждено исходниками:** код или конфигурация присутствуют в указанном коммите.
- **Проверено на стенде:** приложены дата, окружение, действие, фактический вывод и критерий успеха.
- **Запланировано:** рекомендация или ещё не выполненная проверка.

Статус менять только при наличии фактических результатов. Не подставлять выдуманный вывод команд, timestamps или примерный SUCCESS как доказательство.

| Кейс | Нужные артефакты | Runtime-статус |
|---|---|---|
| Развёртывание | Версии, digest, context/profile, четыре Pod/Service и итог запуска | Не проверено |
| Routing | Адреса, маршруты, table 100/rules, шесть направлений и доказательства пути | Не проверено |
| Linux services | Версии пакетов, статусы, порты, прикладные ответы | Не проверено |
| Zabbix | Обезличенные экспорты, свежие метрики, тестовый Problem/Resolved | Не проверено |
| Backup/recovery | Хеши, протокол независимого восстановления файлов/БД, измерения | Не проверено |

## Карточка проверки

Для каждого результата записать:

1. Дату с часовым поясом, исполнителя и точный коммит исходников.
2. Версии Windows, PowerShell, Docker Desktop/Engine, Minikube, Kubernetes, runtime/CNI и digest образа.
3. Предусловия: установленное ПО и важные локальные настройки без секретов.
4. Команду/действие, критерий, фактический результат и код завершения, где применимо.
5. Ссылку на обезличенный лог/скриншот и объяснение редактирования данных.
6. Ограничения, отклонения и условия повторной проверки после изменений.

Рекомендуемые имена будущих файлов: `YYYY-MM-DD-routing.md`, `YYYY-MM-DD-services.md`, `YYYY-MM-DD-zabbix.md`, `YYYY-MM-DD-recovery.md`. Это соглашение об именах, не существующие результаты.

Не включать архивы, дампы, Secret, kubeconfig, пароли, токены и личные адреса. Не публиковать сырые логи без просмотра. Скриншот dashboard не доказывает длительную работоспособность или доставку уведомлений.
